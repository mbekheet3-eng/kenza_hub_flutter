⚠️ IMPORTANT NOTES:
────────────────────────────────────────────

1. You MUST be in the kenza_hub_flutter directory
   (same directory as pubspec.yaml)

2. GitHub will ask for credentials:
   - Username: Your GitHub username
   - Password: Your Personal Access Token (NOT your GitHub password!)
   
   To create a token:
   1. Go to: https://github.com/settings/tokens
   2. Click "Generate new token (classic)"
   3. Select scopes:
      ☑ repo (full control of private repositories)
      ☑ workflow (optional)
   4. Click "Generate token"
   5. Copy the token (you won't see it again!)
   6. Use this as "password" when git asks

3. If you get "fatal: destination path 'kenza_hub_flutter' already exists"
   Delete .git folder first:
   rm -rf .git  (Mac/Linux)
   rmdir .git /s /q  (Windows)
